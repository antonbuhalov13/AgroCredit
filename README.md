# AgroCredit

Учебная информационно-аналитическая система для анализа заявок на кредитные продукты среди представителей аграрных профессий и сельскохозяйственных предприятий. Система принимает заявки, проверяет их, сохраняет в PostgreSQL и показывает аналитику на сайте. Все данные в проекте синтетические.

## Возможности

- **Обзор.** Показатели, графики и таблицы с фильтрами отдельно для физических лиц и предприятий: заявки по регионам, профессиям, сферам, целям и продуктам, динамика по месяцам, доля аграрных заявок.
- **Данные.** Ручной ввод заявки, импорт заявок из CSV с проверкой каждой строки и понятными причинами отклонения, скачивание шаблона CSV.
- **Справочники и проверка.** Для каждого кредитного продукта допустимы только подходящие цели. Для профессии, сферы предприятия и цели есть вариант «Другое» с уточнением, которое сохраняется только в заявке и не меняет общий справочник.
- **Защита данных.** Повторный ID при импорте не перезаписывает существующую заявку. Правила проверки заявок выполняются на сервере и дополнительно закреплены ограничениями в базе.
- **Демонстрационный режим.** Сайт можно открыть без сервера на встроенной демовыборке.
- **ИИ-пояснения к показателям.** В разработке: пояснения строятся только по рассчитанным агрегатам.

## Технологии

HTML, CSS и JavaScript для сайта. Node.js и Express для сервера. PostgreSQL для хранения заявок. SQL для расчёта показателей.

## API

| Метод и адрес | Назначение |
|---|---|
| `GET /api/dictionaries` | Справочники для форм и фильтров |
| `POST /api/applications` | Сохранение заявки из формы |
| `POST /api/upload` | Импорт заявок из CSV |
| `POST /api/analytics` | Показатели, распределения и динамика по выбранным фильтрам |

## Наборы данных

- 14 контрольных заявок с ожидаемыми результатами расчётов для проверки показателей;
- демонстрационные наборы на 300 и 5000 заявок;
- файл со специально ошибочными строками для проверки импорта.

## Запуск

Порядок запуска серверной части, настройка `.env` и подключение к PostgreSQL описаны в `backend/README.md`. Сайт открывается из папки `frontend/` через VS Code Live Server на порту 5500, серверный режим включается параметром `?mode=api`.
